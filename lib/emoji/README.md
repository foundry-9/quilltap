# `lib/emoji` — Tier B of the composer emoji feature

The whole emoji engine: which emoji match a query and in what order, where a `:`
trigger starts and ends, and what the recents list becomes after a pick. Two
surfaces consume it — the inline `:` typeahead and the toolbar picker — so the
two cannot drift apart.

Spec: [`docs/developer/features/complete/composer-emoji.md`](../../docs/developer/features/complete/composer-emoji.md).

## The rule that matters

**Nothing in this directory imports anything.** No React, no Lexical, no Next,
no TanStack, no repo helper — the standard library only. An ESLint
`no-restricted-imports` override scoped to `lib/emoji/**` enforces it in
`eslint.config.mjs`.

That is not fastidiousness. quilltap-v5 (Rust core, Angular SPA, ProseMirror
editor) copies this directory near-verbatim; the ~120 lines that know about
Lexical and React live in `components/chat/`, get rewritten there, and nothing
else has to be re-derived. If a file here needs a DOM type, it belongs in
`components/chat/lexical/`, not here.

`load.ts` is the one boundary case: it touches `fetch`, so it stays thin —
fetch, build, cache, cool down — and holds no decisions.

## Why the fixtures live here and not in `__tests__/fixtures/`

Repo convention puts fixtures under `__tests__/fixtures/`. These sit in
`fixtures/`, beside the engine, **deliberately**: v5 copies `lib/emoji/` as a
directory, and the corpora must travel with the code they pin. Treat them the
way v5 treats `markdown-round-trip.spec.ts` — when a port disagrees, *fix the
port, not the vectors.*

## The dataset is versioned in its filename

`public/emoji/emoji-index.v1.json`, generated by
`scripts/generate-emoji-index.ts` (`npm run generate:emoji-index`) and
committed. A regeneration that changes search results is a **`v2` file plus a
corpus regeneration**, never an in-place edit — otherwise v4 and v5 silently
disagree about what `:smile` means.
